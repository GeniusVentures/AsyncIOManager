## Phase Goal

**As a** downstream consumer of AsyncIOManager (e.g. SuperGenius), **I want to** load a file with `save=true` and have the loaded bytes reliably auto-saved by the registered saver through a registry that no longer carries any parser concept, **so that** the API surface I compile against is honest about what the library does and the save-after-load behavior I rely on is proven by a test rather than by faith.

*(First vertical slice of the ROADMAP Phase 3 goal: registry-level parse removal + auto-save chain proven; the async-signature strip is Plan 02.)*
